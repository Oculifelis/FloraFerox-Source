# Flora Ferox

Source code of [Flora Ferox](https://www.curseforge.com/minecraft/mc-mods/flora-ferox), fierce flowers for Minecraft
(NeoForge 26.1.2): night monsters that wake from their herbs, twelve herbs in four families, grafting, brews, a weapon
line for each class, armour, charms and the Weedwarden villager.

Build with `./gradlew build`.

By Oculifelis. Downloads and the changelog are on CurseForge.
